CSS

Css é uma linguagem declarativa auxiliar a documentos HTML para estilização de definição de comportamento. O css pode ser declarado de três formas distintas:

  • Na tag style, definida no cabeçalho do HTML
  • Em um documento externo por meio da tag link
  • Inline no próprio elemento HTML

Regra CSS

propriedade: Valor;

a última regra que tenha uma mesma especificidade é a que prevalece

CSS possui diversas formas de selecionar em quais elementos uma regra será aplicada.

Seletores:

  • seletor por elemento
  • * seletor universal
  • # identificador único
  • .classe seletor por classe
  • .classe seletor por classe
  • seletor por descendente. Todo x que é descendente/filho de y. Tem diferença entre filho e descendente.
